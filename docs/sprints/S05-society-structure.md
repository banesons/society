# S05 — Society Structure

## Objective
Model and manage physical society infrastructure, including buildings/wings, floors, units/flats, and unit identifiers.

## Scope
### Backend
- Buildings and wings data models and CRUD endpoints.
- Units/flats data models, unique unit identifiers, and unit configuration APIs.
- Unit categorization (e.g., residential, commercial, parking) and area metadata.
- Society structural hierarchy validation rules.

### Frontend
- Society structure management screens for Society Admins.
- Building/wing creation and editing interface.
- Unit inventory list and unit detail views.
- Structural builder or batch creation interface for units.

## Dependencies
- [[S04-society-administration]]

## Deliverables
- Complete physical hierarchy configuration for an active society.
- Unit directory with unique identification per building/wing.
- Administration UI for configuring wings, floors, and units.
