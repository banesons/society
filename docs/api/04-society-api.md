# 04 — Society Onboarding API Specification

## Overview

The Society Onboarding API exposes platform-level endpoints for `SUPER_ADMIN` to register, inspect, activate, suspend, and maintain housing societies.

All endpoints:
- Use prefix `/api/v1/platform/societies`.
- Require S01 Bearer JWT authentication with an active server session.
- Require S02 `SUPER_ADMIN` platform role.
- Adhere to the unified response contract defined in [[../decisions/002-api-contract|ADR 002]].
- Record mutations in `platform_audit_logs`.

---

## 1. List Societies

Retrieves a paginated list of housing societies with optional filtering by lifecycle status and name search.

```http
GET /api/v1/platform/societies?limit=20&offset=0&status=ACTIVE&search=Gokul
Authorization: Bearer <JWT>
X-Session-ID: <session_id>
```

### Query Parameters
| Parameter | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `limit` | Integer | No | `20` | Max items to return (1–100) |
| `offset` | Integer | No | `0` | Number of items to skip |
| `status` | String | No | All | Filter by status (`PENDING`, `ACTIVE`, `SUSPENDED`) |
| `search` | String | No | None | Case-insensitive search on name or society_code |

### Response (`200 OK`)
```json
{
  "success": true,
  "data": {
    "items": [
      {
        "id": "7b63fcf0-3889-4bc2-84cf-d5e6834ff7f1",
        "society_code": "GOKULDHAM-01",
        "name": "Gokuldham Co-operative Housing Society",
        "locality": "Film City Road",
        "city": "Mumbai",
        "state": "Maharashtra",
        "pincode": "400063",
        "status": "ACTIVE",
        "created_at": "2026-10-11T10:00:00Z"
      }
    ],
    "total": 1,
    "limit": 20,
    "offset": 0
  },
  "meta": null
}
```

## 2. Register Society

Registers a new housing society in the platform. Registration always initializes the society in `PENDING` state.

```http
POST /api/v1/platform/societies
Authorization: Bearer <JWT>
X-Session-ID: <session_id>
Content-Type: application/json
```

### Request Payload
```json
{
  "name": "Gokuldham Co-operative Housing Society",
  "registration_number": "MUM/CHS/12345/2020",
  "address_line1": "Plot 10, Goregaon East",
  "address_line2": "Near Film City",
  "locality": "Film City Road",
  "city": "Mumbai",
  "state": "Maharashtra",
  "pincode": "400063",
  "contact_email": "admin@gokuldham.org",
  "contact_phone": "+919820123456"
}
```

> [!NOTE]
> `society_code` is NOT accepted in the request body. It is automatically generated by the Go backend in `SOC-{CITY_CODE}-{RANDOM_SUFFIX}` format (e.g. `SOC-MUM-7K4P2X` for Mumbai, `SOC-PUN-9D3R8A` for Pune).

### Validation Rules
- `name`: Required. 3–255 characters after trimming.
- `address_line1`, `locality`, `city`, `state`: Required, non-empty.
- `pincode`: Required. Exactly 6 digits starting with 1–9 (`^[1-9][0-9]{5}$`).
- `registration_number`: Optional. If provided, must be unique within the state.
- `contact_phone`: Optional. If provided, validated and normalized using canonical phone rules.
- `contact_email`: Optional. If provided, valid email syntax.

### Response (`201 Created`)
```json
{
  "success": true,
  "data": {
    "id": "7b63fcf0-3889-4bc2-84cf-d5e6834ff7f1",
    "society_code": "SOC-MUM-7K4P2X",
    "name": "Gokuldham Co-operative Housing Society",
    "registration_number": "MUM/CHS/12345/2020",
    "address_line1": "Plot 10, Goregaon East",
    "address_line2": "Near Film City",
    "locality": "Film City Road",
    "city": "Mumbai",
    "state": "Maharashtra",
    "pincode": "400063",
    "contact_email": "admin@gokuldham.org",
    "contact_phone": "+919820123456",
    "status": "PENDING",
    "created_by": "a1b2c3d4-0000-0000-0000-000000000000",
    "created_at": "2026-10-11T10:00:00Z",
    "updated_at": "2026-10-11T10:00:00Z"
```

Transitions a society from `PENDING` to `ACTIVE` (or reactivates from `SUSPENDED`).

## 6. Suspend Society

Transitions a society from `ACTIVE` to `SUSPENDED`. Requires a machine-readable reason code from the suspension reason catalogue.

```http
POST /api/v1/platform/societies/{id}/suspend
Authorization: Bearer <JWT>
X-Session-ID: <session_id>
Content-Type: application/json
```

### Request Payload
```json
{
  "reason_id": 1,
  "reason_details": "Billing cycle Q3 overdue beyond 60-day grace period."
}
```
*(Alternatively, `reason_code`: `"PAYMENT_OVERDUE"` is supported for stable business integrations).*

### Validation Rules
- `reason_id` (or `reason_code`): Required. Must resolve to an active record in `society_suspension_reasons` with `allows_manual = true`.
- `reason_details`: Optional for most reasons (max 1000 characters). **Mandatory** when the resolved reason is `OTHER_REVIEW_REQUIRED`.
- Client must not supply `suspension_origin` or `actor_id`; these are derived securely by the backend (`origin = "MANUAL"`).

### Response (`200 OK`)
```json
{
  "success": true,
  "data": {
    "id": "7b63fcf0-3889-4bc2-84cf-d5e6834ff7f1",
    "society_code": "SOC-MUM-7K4P2X",
    "status": "SUSPENDED",
    "updated_at": "2026-10-11T12:00:00Z"
  },
  "meta": null
}
```

## Standard Error Codes

| Error Code | HTTP Status | Meaning |
| :--- | :--- | :--- |
| `SOCIETY_NOT_FOUND` | 404 | Society ID does not exist |
| `SOCIETY_CODE_EXISTS` | 409 | `society_code` is already registered |
| `INVALID_STATUS_TRANSITION` | 400 | Attempted invalid lifecycle transition (e.g. PENDING → SUSPENDED) |
| `ALREADY_IN_STATUS` | 400 | Society is already in the requested status |
| `SUSPENDED_REASON_REQUIRED` | 400 | `reason_code` is missing or empty |
| `INVALID_SUSPENSION_REASON` | 400 | `reason_code` does not exist in the catalogue |
| `SUSPENSION_REASON_INACTIVE` | 400 | Selected `reason_code` is deactivated |
| `MANUAL_SUSPENSION_NOT_ALLOWED` | 400 | Selected `reason_code` is not permitted for manual administrative use |
| `SUSPENSION_DETAILS_REQUIRED` | 400 | `reason_details` is required when selecting `OTHER_REVIEW_REQUIRED` |
| `VALIDATION_ERROR` | 400 | Payload field validation failed (e.g. details exceeding 1000 characters) |
| `FORBIDDEN` | 403 | Caller does not hold `SUPER_ADMIN` platform role |
| `UNAUTHORIZED` | 401 | Missing or invalid authentication token/session |
